# 자연유산 탐구실

비상교육 고등 「한국지리 탐구」 IV-01 **세계유산과 자연경관**을 바탕으로 만든 갯벌 생태계 탐구 프로그램입니다.

## 실행

Node.js 24 및 Python 3 환경에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

3000번 포트에서 정적 사이트를 제공합니다. Python만 있다면 저장소 루트에서 `python3 -m http.server 3000 --bind 0.0.0.0`으로 실행할 수도 있습니다. 정적 호스팅에도 배포할 수 있습니다. 저장소에 코드를 푸시하는 것만으로 사이트가 배포되지는 않습니다.

## 수업 개요 · 45분 초안

| 단계 | 시간 | 학생 활동 |
| --- | --- | --- |
| 개념 발견 | 8분 | 자연유산의 네 가지 가치를 구분하고, 한국의 갯벌과 생물학적 가치를 연결 |
| 갯벌 실험실 | 15분 | 결과를 예상한 뒤 면적·오염·보호 노력 중 한 조건씩 바꾸어 비교, 최대 8회 기록 |
| 일상·낯선 상황 적용 | 12분 | 가상의 산책로 조성 문제와 국제 철새 이동 경로 문제에 개념 적용 |
| 탐구 기록과 성찰 | 10분 | 주장·근거·이유·모형의 한계를 작성하고 PDF로 보관 |

핵심 질문: **갯벌이 줄어들면, 철새와 우리의 삶은 어떻게 달라질까요?**

핵심 개념: 상호 의존, 생물 다양성, 보전.

**별도 개념 기반 탐구 학습 자료는 아직 전달받지 않았습니다.** 위 수업 설계는 사용자가 메시지로 제시한 ‘개념 이해 → 일상 적용 → 낯선 상황 적용’을 바탕으로 한 초안입니다. 별도 자료를 전달받으면 발문·활동 순서·평가 기준을 검토해 반영해야 합니다.

## 교과서 근거와 모형의 구분

첨부 PDF의 인쇄 쪽수를 기준으로 합니다. 교과서 전체나 원본 PDF는 저장소에 배포하지 않습니다.

- 120쪽: 경관적·지질학적·생태학적·생물학적 가치와 등재 시 구성 요소 및 제도적 관리 검토.
- 121쪽: 한국의 갯벌의 2021년 등재 및 생물학적 가치.
- 122쪽: 제주 화산섬과 용암동굴의 지형.
- 123쪽: 갯벌의 다양한 생물과 멸종 위기종, 철새 기착지 역할, 오염 정화와 자연재해 피해 경감 기능.

가상 실험의 계산식과 산책로·해외 습지 문제는 새롭게 구성한 학습 활동으로 **교과서에 있는 수치 실험이나 공식이 아닙니다.** 실제 관측·예측이나 유네스코 등재 판정에 사용할 수 없습니다. 보호 노력만으로 사라진 면적을 대체할 수 없도록 설계했습니다.

A=면적/100, P=오염 부담/100, C=보호 노력/100, H=(1−0.7P)(0.65+0.35C)로 놓고 다음 가상 지수를 반올림해 표시합니다.

- 서식 기반: 100AH
- 철새 쉼터: 100A√H
- 정화 잠재력: 100A(1−0.5P)

모든 결과는 0~100의 설명용 지수입니다. 정화 잠재력은 수질 측정값이 아니며 그림의 새 숫자도 실제 개체 수가 아닙니다. 다른 지역 습지, 종별 특성, 먹이망, 계절, 회복 시간은 계산에 포함되지 않습니다.

## 2D / 3D 관찰

‘갯벌 실험실’ 관찰창에서 **3D 보기**를 선택하면 갯벌 단면과 바다, 철새, 식생을 입체로 관찰할 수 있습니다. 2D와 3D는 같은 입력과 계산 결과를 사용하며 보기 전환으로 실험 조건이나 기록이 바뀌지 않습니다.

- 마우스/한 손가락 드래그: 회전
- 휠/두 손가락: 확대·축소
- 화면 버튼: 좌우 회전, 높낮이, 확대·축소, 시점 초기화
- 3D 화면에 키보드 초점을 두고 방향키: 회전, `+`/`-`: 확대·축소, `Home`: 시점 초기화

갯벌 넓이는 남은 면적을, 점은 오염 부담을, 초록 표지판은 보호 노력의 정도를 나타냅니다. 새와 식생은 상대적인 상태를 보여 주는 상징입니다. 실제 지형·개체 수·수심·지층·복원 결과를 재현하지 않습니다. 3D는 기존 학습용 모형의 시각화이며 별도의 생태 예측 모델이 아닙니다.

현대적인 WebGL 2 지원 브라우저가 필요합니다. 3D를 사용할 수 없거나 그래픽 연결이 끊기면 2D로 돌아가 계속 탐구할 수 있습니다. 그래픽 연결 중단 후에는 새로고침해 3D를 다시 시도할 수 있습니다.

Three.js 0.180.0과 OrbitControls를 라이선스와 함께 `vendor/three`에 포함했습니다. 무결성 확인 및 출처는 해당 폴더의 README를 참고하세요. 3D 요청 시에만 로딩하며 외부 CDN은 사용하지 않습니다. PDF는 기존과 같이 실험 표와 학생의 설명 중심으로 저장합니다.

## PDF와 기록 보관

상단 또는 탐구 기록 화면의 **PDF 만들기**를 누르고 브라우저 인쇄 창에서 **PDF로 저장**을 선택합니다. 이름, 예상, 실험 기록, 적용 활동, 주장과 근거 및 출처가 포함됩니다. 분량에 따라 여러 쪽이 될 수 있습니다. 인쇄 창을 닫은 뒤 ‘탐구실로 돌아가기’로 복귀합니다.

기록은 같은 브라우저·같은 사이트 주소의 로컬 저장소에 보관됩니다. 서버 전송이나 계정 간 동기화는 하지 않습니다. 공용 기기에서는 ‘내 기록 지우기’를 사용하세요. 브라우저 저장이 차단되어도 현재 화면에서 입력·실험·PDF 출력은 가능합니다.

## 검증

```sh
npm test
```

기존 모델 테스트 4개: 갯벌 면적 0의 경계, 면적과 오염의 변화 방향, 보호 노력의 적용 범위, 전체 입력 범위의 지수 상·하한을 확인합니다.

구현 시 Chromium에서 데스크톱 및 390px 모바일 화면, 단계 이동, 기록·삭제, 초기화, 로컬 저장 복원, 적용 문제, PDF 버튼과 한글 PDF 출력, 입력 텍스트 이스케이프, JavaScript 오류 여부를 추가 확인했습니다.

디자인은 `DESIGN-mobbin.md`의 흰 배경, 검은 버튼, 둥근 카드와 필 버튼을 참고했습니다. 생태계 그림은 직접 작성한 SVG입니다.

3D 추가 시 Chromium에서 실제 WebGL 렌더링, 회전·확대·키보드 조작, 조건 연동, 면적 0, 보기 전환, 모바일 너비, 그래픽 연결 중단 및 WebGL 미지원 시 2D 복귀를 검증했습니다.
